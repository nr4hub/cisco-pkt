Build Your First Network

Goal: two PCs connected through one switch that can ping each other.

සිංහල පරිවර්තනය

PC දෙකක් switch එකකට straight-through කේබල් වලින් සම්බන්ධ කර, එකම subnet එකේ IP address (උදා: 192.168.1.10 සහ 192.168.1.11, mask 255.255.255.0) ලබාදී ping කළ විට ජාලය ක්‍රියා කරයි. Link එකේ light කොළ වන තෙක් (තත්පර 30ක් පමණ) රැඳී සිටින්න.

පළමු ping එකේ පළමු reply එක 'Request timed out' වීම සාමාන්‍යයි — හේතුව ARP මගින් MAC address සොයා ගැනීමයි. IP දෙක වෙනස් network වල නම් router එකක් නැතිව ping අසාර්ථක වේ.

සිංහල පරිවර්තනය

Hub එක ලැබෙන signal සියලු ports වලට යවන (Layer 1) පැරණි උපාංගයකි. Switch එක MAC address ඉගෙන ගෙන frame එක අදාළ port එකට පමණක් යවයි (Layer 2). Router එක වෙනස් ජාල සම්බන්ධ කර IP address අනුව packets යොමු කරයි (Layer 3). PC, server වැනි end devices දත්ත යවා ගනී.

කේබල් රීතිය: වෙනස් වර්ගයේ උපාංග → Straight-through; එකම වර්ගයේ උපාංග → Crossover. Console කේබලය භාවිත කරන්නේ router/switch එකක් PC එකකින් configure කිරීමට පමණි. Router ports පෙරනිමියෙන් shutdown වී ඇති නිසා no shutdown දිය යුතුය.

  1. Bottom-left palette → End Devices → drag 2 PCs. Network Devices → Switches → drag a 2960.
  2. Choose Connections → Copper Straight-Through. Click PC0 → FastEthernet0, then Switch → Fa0/1. Repeat PC1 → Fa0/2.
  3. Wait until link lights turn green (switch ports take ~30s to start forwarding).
  4. Click PC → Desktop → IP Configuration and set the address.
  5. Desktop → Command Prompt → ping 192.168.1.11.
Practice lab — simulated (click a PC to configure it)
PC0
C:\>
Try it: set PC0 = 192.168.1.10 and PC1 = 192.168.1.11 → success. Then change PC1 to 192.168.2.11 → fails (different network, no router). Notice the first ping's 1st reply usually times out — that's ARP resolving the MAC address.
⌨ Packet Tracer CLI commands
⌨ Switch: basic setup
enable
configure terminal
hostname SW1
no ip domain-lookup
interface vlan 1
ip address 192.168.1.2 255.255.255.0
no shutdown
exit
interface range fa0/1 - 2
description User ports
end
copy running-config startup-config
⌨ Switch: verify
show mac address-table
show interfaces fa0/1
show ip interface brief
⌨ PC: Command Prompt
ipconfig /all
ping 192.168.1.11
arp -a
