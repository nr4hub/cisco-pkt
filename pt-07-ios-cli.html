The Cisco IOS Command Line

Double-click a router or switch → CLI tab. IOS has modes; the prompt tells you which one you are in.

සිංහල පරිවර්තනය

Cisco IOS හි mode කිහිපයක් ඇත: User EXEC (>), Privileged EXEC (#, enable මගින්), Global config ((config)#, configure terminal මගින්) සහ Interface config ((config-if)#). Prompt එක බලා ඔබ සිටින mode එක හඳුනාගත හැක.

වැදගත් command: show ip interface brief, show running-config, copy running-config startup-config (save කිරීමට අමතක නොකරන්න!). ? ටයිප් කළ විට command ලැයිස්තුව පෙන්වයි; conf t වැනි කෙටි ආකාර ද ක්‍රියා කරයි. Password, SSH සහ banner මගින් උපාංගය ආරක්ෂා කරගත හැක.

Practice CLI (type real commands; try ?)
Essentials: show ip interface brief, show running-config, copy running-config startup-config (save!), exit, end. Abbreviations work: conf t, int g0/0, sh ip int br.
⌨ Packet Tracer CLI commands
⌨ Basic setup (router or switch)
enable
configure terminal
hostname R1
no ip domain-lookup
enable secret Cisco123
service password-encryption
banner motd #Authorized access only#
line console 0
password ConPass1
login
logging synchronous
exec-timeout 10 0
exit
line vty 0 4
password VtyPass1
login
exit
end
copy running-config startup-config
⌨ Enable SSH instead of Telnet
configure terminal
ip domain-name lab.local
username admin secret Admin123
crypto key generate rsa general-keys modulus 1024
ip ssh version 2
line vty 0 4
login local
transport input ssh
end
⌨ Show, save, erase, reload
show running-config
show startup-config
show version
show history
copy running-config startup-config
! from any config mode, run show commands with do
do show ip interface brief
! wipe the device
erase startup-config
reload
