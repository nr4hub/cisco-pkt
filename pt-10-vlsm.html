VLSM — Variable Length Subnet Masks

VLSM gives each subnet the size it actually needs, wasting fewer addresses. Method: sort requirements largest → smallest, then allocate each at the next free address using the smallest block that fits (hosts + 2 ≤ block size).

සිංහල පරිවර්තනය

VLSM මගින් එක් එක් subnet එකට අවශ්‍ය ප්‍රමාණයට අනුව විවිධ mask දී address නාස්තිය අඩු කරයි. ක්‍රමය: අවශ්‍යතා විශාලතම සිට කුඩාම දක්වා පෙළගස්වන්න; එක් එක් එකට (hosts + 2) ට ප්‍රමාණවත් කුඩාම block එක ඊළඟ නිදහස් address එකෙන් ආරම්භයට ලබාදෙන්න.

Router දෙකක් අතර point-to-point link සඳහා host 2ක් පමණක් අවශ්‍ය නිසා /30 භාවිත කරයි. මුළු block ප්‍රමාණය මූලික ජාලයට ඇතුළත් වන්නේදැයි සැමවිටම පරීක්ෂා කරන්න.

Base network/
Hosts needed (comma separated)
Point-to-point router links need only 2 hosts → /30. Always verify the total block sizes fit inside the base network.
⌨ Packet Tracer CLI commands
⌨ Router: 192.168.10.0/24 VLSM plan (100, 50, 25, 10, 2 hosts)
enable
configure terminal
interface g0/0
description LAN-A 100 hosts /25
ip address 192.168.10.1 255.255.255.128
no shutdown
exit
interface g0/1
description LAN-B 50 hosts /26
ip address 192.168.10.129 255.255.255.192
no shutdown
exit
interface g0/2
description LAN-C 25 hosts /27
ip address 192.168.10.193 255.255.255.224
no shutdown
exit
! point-to-point link /30 (needs a serial WIC module)
interface s0/0/0
description Link to R2
ip address 192.168.10.241 255.255.255.252
! clock rate only on the DCE end of the cable
clock rate 64000
no shutdown
end
⌨ Verify
show ip interface brief
show ip route connected
show controllers serial 0/0/0
