DHCP — Automatic IP Addressing

DHCP hands out IP address, mask, gateway and DNS automatically. In Packet Tracer: PC → Desktop → IP Configuration → DHCP. The server can be a Server device (Services → DHCP) or a router.

සිංහල පරිවර්තනය

DHCP මගින් IP address, mask, gateway සහ DNS ස්වයංක්‍රීයව ලබාදේ. ක්‍රියාවලිය DORA ලෙස හැඳින්වේ: Discover (PC එක broadcast කරයි), Offer (server එක ලිපිනයක් පිරිනමයි), Request (PC එක පිළිගනී), Acknowledge (server එක තහවුරු කරයි).

Static ලෙස භාවිතා කරන ලිපින (router, server) ip dhcp excluded-address මගින් pool එකෙන් ඉවත් කළ යුතුය. PC එකට 169.254.x.x ලැබුණේ නම් DHCP අසාර්ථකය (APIPA). Router එකකින් එහා ඇති server එකක් භාවිත කරන්නේ නම් ip helper-address අවශ්‍යයි.

Router as DHCP server

/excluded addresses
A PC showing 169.254.x.x means DHCP failed (APIPA). Across routers, the router needs ip helper-address <dhcp-server> on the client-facing interface.
⌨ Packet Tracer CLI commands
⌨ Router as DHCP server
enable
configure terminal
ip dhcp excluded-address 192.168.1.1 192.168.1.10
ip dhcp pool LAN1
network 192.168.1.0 255.255.255.0
default-router 192.168.1.1
dns-server 8.8.8.8
domain-name school.lk
lease 7
exit
end
⌨ Relay DHCP across a router (client-facing interface)
configure terminal
interface g0/1
ip helper-address 10.0.0.5
end
⌨ Verify, clear & client side
show ip dhcp binding
show ip dhcp pool
show ip dhcp conflict
clear ip dhcp binding *
! router interface as DHCP client
configure terminal
interface g0/0
ip address dhcp
no shutdown
end
! PC Command Prompt
ipconfig /release
ipconfig /renew
