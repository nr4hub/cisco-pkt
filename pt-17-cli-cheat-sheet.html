Quick reference for Packet Tracer. Type to filter; click a command to copy it.

CommandModePurpose
Modes & navigation

configure terminalPrivEnter global configuration (conf t)
interface g0/0ConfigEnter interface mode

line vty 0 4ConfigConfigure remote-access lines
exitAnyGo back one mode
endConfigReturn straight to privileged EXEC
do show ip interface briefConfigRun a show command from config mode
?AnyList available commands
Basic setup & saving
hostname R1ConfigName the device
no ip domain-lookupConfigStop typos being treated as DNS names
enable secret Cisco123ConfigEncrypted privileged password
service password-encryptionConfigEncrypt plain-text passwords
banner motd #text#ConfigLogin warning message

reloadPrivRestart the device
Interfaces & IP

ip address dhcpIfGet address via DHCP
no shutdownIfEnable the interface
description LANIfLabel an interface
clock rate 64000IfSet clock on the DCE serial end

show running-configPrivCurrent configuration
show startup-configPrivSaved configuration

ping 192.168.1.1PrivTest reachability

ACL & NAT

show ip nat translationsPrivActive NAT entries
