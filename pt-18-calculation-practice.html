Calculation Practice — Subnetting, VLAN & VLSM

Try each question on paper first, then open the answer. You can check results with the calculators in topics 4, 5 and 10.

SubnettingS1

Divide 192.168.10.0/24 into 8 equal subnets. Find the new mask, block size, hosts per subnet, and the network, usable range and broadcast of subnet 3.

Borrow 3 bits (2³ = 8) → /27 = 255.255.255.224.
Block size = 256 − 224 = 32; hosts = 2⁵ − 2 = 30.
Subnet 3 starts at 2 × 32 = 64 → network 192.168.10.64/27, usable .65 – .94, broadcast 192.168.10.95.
SubnettingS2

Host 172.16.45.200/20: find the subnet mask, network address, broadcast address and number of usable hosts.

/20 → mask 255.255.240.0; block size in the 3rd octet = 16.
45 ÷ 16 → 2 × 16 = 32 → network 172.16.32.0/20.
Broadcast = next network (172.16.48.0) − 1 = 172.16.47.255; usable 172.16.32.1 – 172.16.47.254.
Hosts = 2¹² − 2 = 4094.
SubnettingS3

Host 10.10.10.130 with mask 255.255.255.192: find the network, first host, last host, broadcast and usable hosts.

255.255.255.192 = /26; block size = 64. 130 → 2 × 64 = 128.
Network 10.10.10.128, first host .129, last host .190, broadcast 10.10.10.191.
Usable hosts = 2⁶ − 2 = 62.
SubnettingS4

A network must hold at least 500 hosts. What is the smallest prefix length and its subnet mask?

Need 2h − 2 ≥ 500 → h = 9 (510 hosts; h = 8 gives only 254).
Prefix = 32 − 9 = /23 → mask 255.255.254.0.
SubnettingS5

With mask 255.255.255.192, are 192.168.5.97 and 192.168.5.130 in the same subnet? Can they ping without a router?

Block size 64: .97 lies in 192.168.5.64/26 (64–127); .130 lies in 192.168.5.128/26 (128–191).
Different subnets → they cannot communicate without a router (and correct gateways).
SubnettingS6

From 172.16.0.0/16 you need subnets of 100 hosts each. Which prefix? How many such subnets are available?

100 hosts → 7 host bits (2⁷ − 2 = 126; 6 bits gives only 62) → /25.
Borrowed bits = 25 − 16 = 9 → 2⁹ = 512 subnets.
VLANV1

A 24-port switch (Fa0/1–Fa0/24) uses Fa0/21–24 as trunks. The remaining ports are split equally among VLANs 10, 20, 30 and 40. (a) Ports per VLAN? (b) Give each VLAN's port range.

(a) 24 − 4 = 20 ports ÷ 4 VLANs = 5 ports per VLAN.
(b) VLAN 10 → fa0/1 - 5; VLAN 20 → fa0/6 - 10; VLAN 30 → fa0/11 - 15; VLAN 40 → fa0/16 - 20.
Example: interface range fa0/1 - 5 → switchport mode access → switchport access vlan 10.
VLANV2

Use 192.168.50.0/24 with one /27 per VLAN: VLAN 10 Sales (28 hosts), VLAN 20 HR (12), VLAN 30 IT (5). The router gateway is the first usable address of each subnet. Give the router-on-a-stick sub-interface addresses.

/27 holds 30 hosts, so it fits all three (28 ≤ 30). Subnets: .0, .32, .64.
g0/0.10 → 192.168.50.1 255.255.255.224 (net 192.168.50.0/27)
g0/0.20 → 192.168.50.33 255.255.255.224 (net 192.168.50.32/27)
g0/0.30 → 192.168.50.65 255.255.255.224 (net 192.168.50.64/27)
Each needs encapsulation dot1Q <vlan-id>.
VLANV3

All ports of a switch belong to VLANs 10, 20 and 30 (none in VLAN 1). (a) How many broadcast domains? (b) How many router sub-interfaces are needed for router-on-a-stick? (c) How many physical router interfaces are needed?

(a) One broadcast domain per VLAN = 3.
(b) One sub-interface per VLAN = 3.
(c) All three share one trunk link = 1 physical interface (e.g. g0/0, split into g0/0.10, .20, .30).
VLANV4

A trunk is set with switchport trunk allowed vlan 10,20,30-33. How many VLANs does it carry? How many VLAN IDs exist in total (1–4094)?

10, 20, 30, 31, 32, 33 → 6 VLANs (the range 30-33 adds 4; 10 and 20 add 2).
Total VLAN IDs 1 – 4094 = 4094.
VLANV5

Each VLAN in 192.168.100.0/24 uses a /26. (a) Usable hosts per VLAN? (b) How many VLANs fit? (c) If VLAN 3 is the third subnet and the gateway is its first usable address, what is the gateway?

(a) 2⁶ − 2 = 62 hosts.
(b) 2² = 4 VLANs (.0, .64, .128, .192).
(c) Third subnet = 192.168.100.128/26 → gateway 192.168.100.129.

VLSMM3

(a) Do requirements of 120, 60, 30 and 14 hosts fit in a /24? (b) Do 130 and 60 hosts fit in a /24?

(a) Blocks: 128 (/25) + 64 (/26) + 32 (/27) + 16 (/28) = 240 ≤ 256 → Yes, with 16 addresses left over.
(b) 130 hosts needs 8 host bits (/24 = 256 addresses) → it uses the whole /24, leaving no room for the 60-host LAN (needs a /26) → No. Use a larger base network, e.g. a /23.
